Checking the numbers in MTF

  • Open the MTF admin Usage report and go to the Web Projects tab, then filter to this project and the current date range.
  • Usage and page views are reported by the MTF analytics pipeline, so figures may not appear immediately after a load. Check again after some time.
  • If the project restricts allowed domains, the domain this page is served from must be on that list for the load to be counted.
  • Use the reload button (or open the page in several tabs and browsers) to produce more page views.
